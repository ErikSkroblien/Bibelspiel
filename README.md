## 🎲 Worum geht's?

Würfeln, Felder hüpfen und Bibelfragen beantworten. Mit **Leitern** 🪜 geht es nach oben, auf **Rutschen** 🛝 geht es wieder zurück. Wer zuerst das Ziel auf **Feld 66** erreicht, gewinnt! 🏆

> 💡 66 Felder, so viele, wie die Bibel Bücher hat.

## ✨ Features

| | Funktion |
|---|---|
| 🧍‍♂️ | Mehrere Spielfiguren in 3D-Optik |
| 🦘 | Figuren hüpfen sichtbar Feld für Feld |
| 🪜 | Leitern bringen dich schnell nach vorne |
| 🛝 | Rutschen schicken dich zurück |
| ❓ | Bibelfragen bei jedem Zug |
| 🔁 | Bei richtiger Antwort darfst du nochmal würfeln |
| 👀 | Gesamtansicht: Alle Figuren sind immer zu sehen |
| 🎵 | Ruhige Hintergrundmusik mit Ein/Aus-Schalter und Lautstärkeregler |
| 📱 | Läuft direkt im Browser, ohne Installation |

## 🕹️ Spielanleitung

1. 👥 Spieler und Figuren auswählen
2. 🎲 Würfeln
3. 🦘 Die Figur hüpft vorwärts
4. ❓ Frage beantworten:
   - ✅ **Richtig:** nochmal würfeln
   - ❌ **Falsch:** der nächste Spieler ist dran
5. 🪜 Auf einer Leiter geht es nach oben, 🛝 auf einer Rutsche nach unten
6. 🏁 Wer zuerst das Ziel erreicht, gewinnt!
